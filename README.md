# سوّي · الموقع

موقع سوّي على GitHub Pages. HTML وCSS بدون إطار عمل.

- `assets/css/tokens.css`: الألوان والخطوط والمسافات من نظام تصميم سوّي.
- `assets/css/components.css`: المكوّنات (`sw-`) من نظام التصميم.
- `assets/css/site.css`: تخطيط الصفحات.

الحالة: الصفحة الرئيسية فقط. باقي الصفحات (المشاريع، سوّي نظام، الورشة، عن سوّي) قيد البناء.
